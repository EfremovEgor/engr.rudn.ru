# Руководство редактора

Админка: `https://academy.rudn.ru/admin-<суффикс>/`.

## Как устроена любая форма

- Вверху — общие поля (дата, изображение, связи, «Опубликовано»).
- Ниже — вкладки **🇷🇺 Русский** и **🇬🇧 English** с текстами. Русская версия обязательна там,
  где поле обязательно; английскую можно заполнить позже.
- Под каждым английским полем серым показан русский оригинал — переводить удобно, не переключая вкладки.
- Если английское поле пустое, на английской версии сайта будет показан русский текст.
- Снимите «Опубликовано», чтобы скрыть материал, не удаляя его.
- Порядок элементов (кафедры, слайды, документы, семинары) меняется перетаскиванием в списке.

## Частые задачи

**Новость.** «Материалы сайта → Новости → Добавить». Обложка автоматически обрезается до 4:3.
Тэги выбираются из списка; новый тэг создаётся кнопкой «+» рядом с полем.

**Программа обучения.** «Образование → Образовательные программы». Внизу формы — условия приёма для каждой
формы обучения (места, срок, стоимость). Минимальные баллы редактируются по ссылке «Изменить» у условий приёма.
Названия предметов переводятся один раз в разделе «Предметы испытаний» — прямо в списке.

**Доклад семинара.** Откройте семинар — доклады в таблице внизу. Аннотация, материалы, видео — по ссылке
«Изменить» у доклада. Ссылку на доклад можно открыть кнопкой «Смотреть на сайте».

**Документ.** «Материалы сайта → Документы»: выберите раздел (нормативные документы, дни открытых дверей,
образцы заявлений). Для английской версии можно загрузить отдельный файл.

**Новая страница.** «Материалы сайта → Страницы»: укажите адрес (например, `science/new-lab`), заголовок
и текст. Страница откроется по адресу `https://academy.rudn.ru/science/new-lab`
(английская — `/en/science/new-lab`).

**Страница научного центра.** Заполните «Подробное описание» — оно заменит старую свёрстанную страницу.

## Изображения и файлы

- Кнопка **«Медиатека: вставить файл или изображение»** под каждым редактором открывает библиотеку:
  клик по изображению вставляет его в текст, по документу — ссылку на него.
- Кнопка «Изображение» в панели редактора загружает файл с компьютера — он тоже попадает в медиатеку.
- Раздел «Медиатека»: загрузка нескольких файлов перетаскиванием, папки, поиск, копирование ссылки.
  На странице файла видно, где он используется. Файл, который где-то используется, с диска не удаляется.

## Переводы

- «Переводы контента» — сколько записей в каждом разделе не переведено; клик по числу открывает список.
- В любом списке есть фильтр «Перевод на английский» и колонка EN.
- «Строки интерфейса (.po)» — подписи меню, кнопок и тексты свёрстанных страниц. Доступно суперпользователям
  и группе `translators`.
